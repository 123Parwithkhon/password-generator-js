A sleek, responsive, and feature-rich **Random Password Generator** web application built with HTML5, CSS3, and Vanilla JavaScript. Designed with a modern dark theme and FontAwesome icons for a smooth user experience.

🔗 **[View Live Demo](https://123parwithkhon.github.io/password-generator-js/)** *(доступно после включения GitHub Pages)*

---

## ✨ Features
- **Customizable Length:** Interactive range slider allowing users to generate passwords from 8 to 20 characters long.
- **Instant Generation:** Generates secure random strings including uppercase/lowercase letters, numbers, and special symbols (`!`, `$`, `%`, `&`, etc.).
- **One-Click Copy:** Easily copy the generated password directly to the clipboard with visual confirmation.
- **Modern Dark UI:** Styled with a sleek dark aesthetic (`#1c1e21`), vibrant blue gradients, FontAwesome buttons, and monospaced font output (`Roboto Mono`).

---

## 🛠️ Tech Stack & Concepts Applied
- **HTML5 & FontAwesome:** Semantic form elements, interactive range inputs, and vector UI icons.
- **CSS3:** Linear gradients, box shadows, custom webkit slider styling, and absolute positioning.
- **Vanilla JavaScript (DOM Manipulation & Events):**
  - Array/String manipulation for character set combination.
  - Pseudo-random character picking (`Math.random()`).
  - Dynamic UI binding (`oninput`, `onclick`, range value tracking).
  - Clipboard interaction via legacy and modern DOM selection methods.
